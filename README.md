# Character Chemistry Manager

Расширение SillyTavern с персонажными пресетами поведения. Это самостоятельная переработка идеи Fetish Manager: вместо одного набора на чат можно создать библиотеку персонажей, прикрепить к текущему чату несколько пресетов и отдельно переключать каждому режим **Flirt / Spicy / Sex**.

## Что умеет

- несколько персонажей в одном чате;
- отдельные наборы промптов для Flirt, Spicy и Sex;
- индивидуальная сила 1–10 и частота 0–100% у каждого промпта;
- общий конструктор, который можно включить поверх персонажных пресетов;
- заготовки из старого менеджера без автоматического включения;
- импорт и экспорт отдельного профиля персонажа;
- импорт и экспорт полной переносимой JSON-копии библиотеки;
- однократный перенос активных настроек из `fm_v2` / `fm` в общий конструктор;
- компактный интерфейс для ноутбука и телефона;
- оформление штатными компонентами SillyTavern: расширение не задаёт собственные цвета, шрифт, прозрачность, рамки или тени и следует активной теме;
- редактирование промпта в родном окне SillyTavern вместо постоянно развёрнутых карточек.

## Где хранятся данные

Библиотека персонажей и общий конструктор сохраняются в серверном объекте настроек SillyTavern `extensionSettings.character_chemistry_manager`. Это не `localStorage`, поэтому один профиль SillyTavern видит одинаковую библиотеку с телефона и ноутбука.

Список прикреплённых персонажей и их текущие режимы сохраняются в `chatMetadata.character_chemistry_manager` — прямо в метаданных конкретного чата. У каждого чата свой состав.

В разделе **Персонажи** можно экспортировать открытый профиль в отдельный JSON и импортировать его как новый независимый пресет. Совпадающее имя не затирается: импортированная копия получает пометку «импорт». Отдельно в настройках остаётся полная резервная копия всей библиотеки и конструктора. Привязки чатов в неё не входят, потому что они уже принадлежат своим чатам.

## Установка

1. Поместите папку `character-chemistry-manager` в `SillyTavern/public/scripts/extensions/third-party/`.
2. Перезагрузите страницу SillyTavern.
3. Откройте **Extensions → Character Chemistry Manager**.

## Как пользоваться

1. В разделе **Персонажи** создайте пресет.
2. Откройте Flirt, Spicy или Sex, добавьте промпт и заполните его в открывшемся окне SillyTavern. Позже достаточно нажать на строку промпта, чтобы изменить её.
3. В разделе **Чат** прикрепите одного или нескольких персонажей.
4. Переключите режим напротив каждого имени.
5. При каждой новой генерации каждый активный промпт независимо проверит свою частоту. `/quiet`, impersonate и continue не создают новый бросок.

## Происхождение
